# review_bot

내 컴퓨터에서 도는 GitHub PR 리뷰 봇입니다. 이미 쓰고 있는 ChatGPT(`codex`)나 Claude(`claude`) 구독으로 PR 을 리뷰하고, 레포가 적어 둔 규칙과 내가 기각한 지적에서 배워 다음 리뷰를 고칩니다. API 키, 서버, 데이터베이스가 필요 없습니다.

## 빠른 시작

필요한 것은 세 가지입니다.

1. [Node.js](https://nodejs.org) 22 이상
2. [GitHub CLI](https://cli.github.com) 로그인 — `gh auth login`
3. 리뷰 모델 하나 — `codex` 또는 `claude` CLI 로그인
   - ChatGPT 구독: `npm i -g @openai/codex` 후 `codex login`
   - Claude 구독: `npm i -g @anthropic-ai/claude-code` 후 `claude` 를 한 번 실행해 로그인

그다음 이 레포에서:

```bash
git clone https://github.com/JSL107/review_bot.git
cd review_bot
npm install        # pnpm install 도 됩니다
npm run dev        # 브라우저가 http://127.0.0.1:4317 로 열립니다
```

첫 화면의 **시작하기**가 남은 일을 알려 줍니다. 환경 점검에서 막힌 항목은 바로 아래에 실행할 명령이 나옵니다. 대시보드 없이 점검만 하려면 `npm run check` 를 실행하세요.

처음에는 레포를 고를 때 **"리뷰를 PR 에 바로 게시"를 끈 채로** 두기를 권합니다. 리뷰가 대시보드에만 쌓이므로, 결과가 마음에 들 때 리뷰 탭의 "게시 미리보기"에서 직접 게시하면 됩니다.

## 대시보드에서 할 수 있는 일

- **대시보드**: 지금 하고 있는 작업과 단계, 경과 시간, 최근 8주 채택·기각 추이, 지적 종류별 분포, 레포별 채택률을 봅니다. "지금 PR 찾기"와 "지금 반응 걷기"로 자동 작업을 바로 돌릴 수 있습니다.
- **리뷰**: PR 주소를 넣어 리뷰합니다. 지난 리뷰는 레포·상태로 거르고 검색할 수 있습니다. **게시 미리보기**는 어느 파일 몇 번째 줄에 무엇이 달릴지 보여 주고, 확인한 뒤에 게시합니다.
- **학습**: 답글만 달리고 👍·👎 가 없는 지적을 채택·기각으로 판정하고, 다음 리뷰에 실릴 규약을 미리 보고, 잘못 배운 기각을 학습에서 뺍니다.
- **설정**: 내 GitHub 레포 목록에서 검색해 감시할 레포를 고르고, 레포마다 자동 리뷰·바로 게시·리뷰할 PR 범위·학습 사용·규칙 문서를 정합니다.

켜 두면 정해진 주기(기본 10분)마다 열린 PR 을 찾아 리뷰합니다. 이미 본 커밋은 건너뛰고 새 push 만 다시 봅니다. 리뷰는 한 번에 하나씩 차례로 돕니다.

## 리뷰가 배우는 방법

**레포 규칙.** PR 의 기본(base) 브랜치에서 `AGENTS.md`·`CLAUDE.md`·`CODE_RULES.md`·`.github/copilot-instructions.md`·`REVIEW.md` 를 읽어 리뷰에 싣습니다. PR 작성자가 규칙 파일을 고쳐 자기 PR 의 기준을 바꾸지 못하도록 head 가 아닌 base 에서 읽습니다. 문서에 `## Code Review Rules`(또는 `## 리뷰 규칙`) 섹션이 있으면 그 섹션만 씁니다. 설정에서 레포별 규약을 직접 적을 수도 있습니다.

**기각에서 배우기.** 봇이 단 코멘트에 👍 를 누르면 채택, 👎 를 누르면 기각입니다. 👎 와 함께 **내가 단 답글**이 기각 사유가 됩니다. 최근 90일 안에 같은 종류의 지적이 40자 이상 사유와 함께 두 번 이상 기각되면, 다음 리뷰부터 "이 레포에서는 정상"이라는 규약으로 실립니다. 사유는 내 gh 계정의 답글만 씁니다. 공개 레포에서 남이 PR 을 올려 자기 답글로 규약을 만들지 못하게 하려는 것입니다. 보안 지적은 몇 번 기각돼도 학습하지 않습니다.

## 터미널에서 한 번만 쓰기

```bash
npm run cli -- owner/repo#123 -m claude          # 결과를 터미널에 출력
npm run cli -- owner/repo#123 -m codex --comment # 확인 후 PR 에 게시
npm run cli                                      # 선택 화면
```

`npm run build && npm link` 를 하면 어디서나 `pr-review` 로 부를 수 있습니다. 옵션은 `pr-review --help` 를 보세요. 터미널로 돌린 리뷰도 대시보드와 학습에 함께 쌓입니다.

## 안전장치

- 대시보드 서버는 내 컴퓨터(`127.0.0.1`)에서만 열립니다. 다른 웹사이트가 브라우저를 통해 이 서버로 게시를 일으키지 못하도록 요청 출처를 검사합니다.
- 리뷰 모델은 파일을 읽지 못하는 상태로 띄웁니다. codex 는 빈 임시 폴더만 읽게 잠그고, claude 는 도구·MCP·사용자 설정을 끕니다. 악의적인 PR 이 내 컴퓨터의 파일을 읽혀 코멘트로 내보내지 못하게 하려는 것입니다.
- `.env`·`*.pem` 같은 비밀 파일은 내용을 모델에 보내지 않습니다.
- 게시는 항상 "코멘트" 리뷰입니다. 승인이나 수정 요청은 사람이 합니다. 리뷰 뒤 새 커밋이 올라오면 게시를 거절하고 다시 리뷰하라고 알려 줍니다.
- "바로 게시"를 켜는 순간 확인 창이 뜹니다. 켠 레포는 사람 확인 없이 내 계정으로 코멘트를 답니다.

## 설정과 데이터

| 항목 | 기본값 | 바꾸는 법 |
|---|---|---|
| 상태 파일 (설정·리뷰·학습 기록) | `~/.review_bot/state.json` | `REVIEW_BOT_HOME=폴더` |
| 포트 | 4317 | `PORT=4318 npm run dev` |
| 브라우저 자동 열기 | 켬 | `NO_OPEN=1 npm run dev` |
| codex 모델 | `~/.codex/config.toml` 의 모델 | 대시보드 설정의 "세부 모델" |
| claude 모델 | 계정 기본값 | 대시보드 설정의 "세부 모델" |

## 문제 해결

- **포트를 이미 쓰고 있다고 나옵니다**: 이미 켜져 있을 수 있습니다. http://127.0.0.1:4317 을 열어 보세요. 다른 포트로 켜려면 `PORT=4318 npm run dev`.
- **리뷰가 "빈 응답"이나 "exit=1" 로 실패합니다**: 모델 CLI 의 로그인이 풀렸거나 구독 사용량을 다 쓴 경우입니다. `npm run check` 로 확인하세요.
- **레포 목록이 비어 있습니다**: `gh auth status` 로 로그인 상태와 권한을 확인한 뒤 설정의 "목록 새로고침"을 누르세요.
